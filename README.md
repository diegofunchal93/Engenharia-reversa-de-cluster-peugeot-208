# Engenharia-reversa-de-cluster-peugeot-208
Decodificação e simulação de rede CAN peugeot 208

## Objetivos
- Capturar e interpretar mensagens CAN do painel de intrumentos.
- Simulação de RPM,velocidade e manipulação de todas as luzes de advertencia.

## Ferramentas utilizadas:
Arduino Nano
MCP2515 CAN Module
Software CanHacker
Osciloscópio LOTO OSC482X + analisador lógico
Painel de instrumentos peugeot 208
Fonte de bancada
Cabos elétricos

## Estrutura do repositório
- Biblioteca arduino/MCP2515 CAN
- Imagens de exemplo dos sinais capturados e comportamento do painel
- Datasheet MCP2515
- Arquivo DBC para análise
- ** Arquivo DBC,esquema elétrico e biblioteca MCP2515 disponiveis
